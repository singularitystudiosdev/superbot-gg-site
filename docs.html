quickstart

one line puts superbot on this machine full time. it wires every AI client through your own subscriptions, then keeps working 24/7: it fixes the slow bits, the repeats and the boring errors. pick an arm below, the terminal line or the paste.

1install

no terminal? paste this to any coding agent and let it take it from there: install the Superbot MCP server globally: https://superbot.gg/mcp

2verify

restart your AI client, then ask it what superbot tools it has. you should see one tool, superbot. running it may ask you to pair once.

3try it

paste a prompt, get an answer. ask for something it can't do yet, and it learns it.

4keep it current

re-running the install line is the update. it always pulls the current installer. undo everything with --uninstall.

per-client manual setup

the bootstrap writes every client it finds. prefer to wire one by hand? each recipe is a short page.

troubleshooting

client doesn't show superbot: restart it. configs are written while the client is closed or reloaded.

no node on the machine: the install line installs it (brew on mac, winget on windows, official build into ~/.local on linux; no sudo).

pairing prompt: running a tool may ask you to pair once; that ties this device to your account.

uninstall: curl -fsSL https://superbot.gg/install/uninstall.sh | sh removes the entry from every client and restores what it changed. windows: powershell -c "irm https://superbot.gg/install/uninstall.ps1 | iex".
